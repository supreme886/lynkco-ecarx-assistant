# 车机助手 v1.6（平台签名版）

适用于**领克车机（ECARX AdaptAPI / Android 9）**。已在 **2022 款领克 05、车机系统版本 731** 上实测通过。

## 这个 APK 能做什么

**① 开机自动切换到指定驾驶模式**

- 开机后自动轮询等待车辆信号，就绪即写入，无需等固定时间；
- 可选：舒适 / 经济 / 运动 / 个性化；
- 已是目标模式则跳过写入；写入后读回校验，异常自动回滚；
- 整个过程静默完成，成功后 Toast 提示一次。

**② 驾驶模式一变，自动关闭「智能启停」**

- 无论模式由物理按键、车机原生设置页还是本 APK 切出，都会被捕获；
- 模式变化 1.5 秒后自动关闭启停，失败重试最多 3 次；
- 关闭后 6s / 15s 各复查一次，被车机自己顶开会再关一次；
- 开机时不主动操作启停，只响应模式切换。

**③ 手动控制**

- 「立即切换到所选模式」「立即关闭智能启停」两个按钮；
- 顶部实时显示当前驾驶模式与启停状态。

两个功能**完全独立**，可以只开其中一个。

## 安装

```bash
adb connect <车机IP>:5555
adb install -r CarAssistant-v1.6-platform.apk
```

装不上时依次确认：

1. 车机是否已开启 ADB（工程模式 / 开发者选项）；
2. 该 ROM 是否用 **AOSP test-keys** 签名 —— 若 ROM 用的是厂商自有平台签名，这个包会因签名不匹配而装不上，需自行用匹配的签名文件重新签名（`tools/sign-platform.sh`）；
3. 是否与已安装的旧版本冲突，卸载旧版后重试。

安装后打开「车机助手」，选择模式、打开需要的开关即可。日志排查：

```bash
adb logcat -s CarAssistant
```

## 已知限制

- 仅验证了 2022 款领克 05 / 系统版本 731；其他车型与系统版本请自测；
- 依赖反射调用车机私有接口，**OTA 升级后可能失效**；
- 修改车辆设置有风险，详见仓库 README 的免责声明；
- 本项目为个人自用工具，与领克、吉利、亿咖通无任何关联。
